⚙️ Sekali Saja: Hubungkan ke Firebase

Agar kalender ini bisa dipakai bersama-sama (usulan tersimpan untuk semua orang), Anda perlu membuat database gratis di Firebase (milik Google), lalu tempelkan kode konfigurasinya di file ini.

  1. Buka console.firebase.google.com, login dengan akun Google, klik Add project / Tambah project, beri nama bebas (mis. kalender-pendidikan), lalu selesaikan pembuatan project.
  2. Di menu kiri, buka Build → Realtime Database → klik Create Database. Pilih lokasi server (mis. Singapore), lalu pilih mode Start in test mode → Enable.
  3. Di menu kiri, buka Project settings (ikon gerigi) → scroll ke bawah ke bagian Your apps → klik ikon </> (Web) → beri nama app → Register app.
  4. Firebase akan menampilkan kode firebaseConfig. Salin seluruh isinya.
  5. Buka file HTML ini dengan editor teks (Notepad/VS Code), cari bagian FIREBASE_CONFIG di dekat awal tag <script> paling bawah, dan ganti isinya dengan yang Anda salin dari Firebase.
  6. Simpan file, lalu upload ulang ke GitHub (Add file → Upload files → Commit changes, timpa file lama). Tunggu 1 menit, refresh halamannya.

Catatan: mode "test" pada Realtime Database berarti siapa pun yang tahu alamat database bisa membaca/menulis data secara langsung (bukan hanya lewat halaman ini). Ini cukup aman untuk pemakaian internal sekolah, tapi bukan pengamanan tingkat tinggi. Anda bisa memperketat aturan akses nanti lewat menu Rules di Firebase jika diperlukan.
